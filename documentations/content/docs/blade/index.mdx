# Laravel Blade

The `stria-icons/blade` package provides Blade directives and components to seamlessly integrate Stria Icons into your Laravel applications.

## Installation

```bash
composer require stria-icons/blade
```

## Usage

You can use the anonymous component syntax:

```html
<x-stria-icon name="camera-regular" class="w-6 h-6 text-gray-500" stroke-width="1.5" />
```
