Because Stria React components render native inline SVGs, they inherit the text color of their parent element by default (`currentColor`). 

This means icons will automatically adapt to your application's light and dark mode themes. You can color them by setting text color on their wrapper or applying a custom className.

## Basic Coloring

In React, since the SVG uses `fill="currentColor"`, you can color the icon just like text.

## The Duotone Style

The **Duotone** style is unique because it consists of **two separate paths**: a primary layer and a secondary layer.

By default, both layers inherit the same `currentColor`, but the secondary layer has an automatic `40%` opacity applied to it. This creates a sophisticated, translucent two-tone effect using just a single color code.

If you want absolute control, you can define two completely different colors for the layers by targeting the paths inside the SVG component using CSS selectors. By convention, the first path is the secondary layer, and the second path is the primary layer.

### CSS Setup

```css
/* global.css or app.css */
.icon-duotone-custom path:nth-child(1) {
  fill: #ef4444; /* Red secondary */
  opacity: 1;    /* Remove default 40% opacity */
}
.icon-duotone-custom path:nth-child(2) {
  fill: #3b82f6; /* Blue primary */
}
```

### Component Usage

```tsx
import { LayerGroupDuotone } from '@stria-icons/react';

export default function CustomIcon() {
  return (
    <LayerGroupDuotone className="icon-duotone-custom w-8 h-8" />
  );
}
```
