# React Wrapper

The `@stria-icons/react` package provides React component wrappers for Stria Icons. Each icon is exported as a separate functional component, allowing for tree-shaking and efficient bundling.

## Key Features

- **Tree Shakeable**: Import only the icons you use in your application.
- **TypeScript Support**: Full type definitions included out of the box.
- **Customizable**: Pass classes and styles directly to change color, size, and layout.
- **Optimized**: Fast render times with lightweight SVG outputs.

## Performance

Because every icon variation is compiled into a standalone React component, your bundler (webpack, Vite, Rollup) can easily shake off unused code. Only the icons you actually render in your application will be included in the final JS bundle.
