# Stria Icons

**Stria Icons** is a premium, open-source SVG icon library designed for modern user interfaces. It provides a meticulously crafted set of icons that are beautiful, consistent, and highly customizable.

## Design Philosophy

Stria Icons follows a strict design system to ensure visual consistency across all icons:

- **Consistent Grid**: Designed on a 24x24 grid.
- **Stroke and Fill**: Available in multiple distinct styles including Solid, Regular, Light, Thin, and Duotone.
- **Scalability**: Perfect vector scalability from tiny UI elements to large illustrations.
- **Accessibility**: Built with best practices for web accessibility.

## Framework Agnostic

While Stria Icons provides first-class support for **React** and **Laravel Blade**, the core SVG assets are completely framework agnostic. You can use our sprite sheets and raw SVGs in any vanilla HTML, Vue, Svelte, or Angular project.
