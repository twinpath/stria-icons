# Installation

To use Stria Icons in your React or Next.js application, install the official `@stria-icons/react` package.

## Install the Package

<PackageInstall type="npm" packageName="@stria-icons/react" />

## Basic Usage

Import the desired icon component and render it. You can customize the size and color via standard props.

```tsx
import { AddressBookSolid, CameraRegular } from '@stria-icons/react';

export default function MyComponent() {
  return (
    <div className="flex gap-4 text-blue-600">
      {/* Inherits color from parent div */}
      <AddressBookSolid size={24} />
      
      {/* Custom size override */}
      <CameraRegular size={32} />
    </div>
  );
}
```
