# Core Package

The `@stria-icons/core` package contains the raw SVG assets, optimized SVG sprites, and generic CSS utilities. This is the foundation upon which all other wrappers are built.

## Installation

```bash
npm install @stria-icons/core
```

## Usage

Use the SVG sprite directly in your HTML:

```html
<svg class="stria-icon" width="24" height="24">
  <use href="node_modules/@stria-icons/core/dist/sprite.svg#camera-regular"></use>
</svg>
```
