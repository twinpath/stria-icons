# Laravel Blade Wrapper

The `stria-icons/blade` package provides Blade directives and components to seamlessly integrate Stria Icons into your Laravel applications.

Each icon is rendered as inline SVG, allowing you to style, color, resize, and optimize them with custom CSS or utility-first frameworks like Tailwind CSS.

## Key Features

- **Anonymous Blade Components**: Render icons with clean syntax (e.g. `<x-stria-regular-home />`).
- **Direct SVG Rendering**: Raw SVGs are compiled and injected directly into the HTML response.
- **Style Customization**: Forward styles, class names, and arbitrary attributes directly to the underlying SVG.
- **Zero Configuration**: Register and render icons out-of-the-box after installation.
