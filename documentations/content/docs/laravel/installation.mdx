# Installation

To use Stria Icons in your Laravel Blade views, install the official `stria-icons/blade` package using Composer.

## Install the Package

<PackageInstall type="composer" packageName="stria-icons/blade" />

## Basic Usage

Use the anonymous component syntax directly in your Blade views:

```html
<!-- Regular style -->
<x-stria-regular-camera class="w-6 h-6 text-gray-500" />

<!-- Solid style -->
<x-stria-solid-camera class="w-6 h-6 text-gray-500" />
```
