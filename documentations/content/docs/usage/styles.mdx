Stria Icons provides 5 distinct visual styles for every icon: **Solid**, **Regular**, **Thin**, **Light**, and **Duotone**. 

Unlike stroke-based icons, Stria Icons are meticulously crafted as **fill-based geometric shapes**. This guarantees pixel-perfect rendering across all devices without the distortion caused by CSS `stroke-width` scaling.

To change the visual weight or style of an icon, you switch the style parameter rather than modifying CSS strokes.

## Applying Styles

<Tabs items={['Vanilla HTML', 'React', 'Laravel Blade']}>
  <Tab value="Vanilla HTML">
    When using the Vanilla package (CSS Masking), styles are applied using the `stria-{style}` utility class alongside the icon name.

    ```html
    <!-- Solid (Default) -->
    <i class="stria-solid stria-home"></i>

    <!-- Regular -->
    <i class="stria-regular stria-home"></i>

    <!-- Light -->
    <i class="stria-light stria-home"></i>

    <!-- Thin -->
    <i class="stria-thin stria-home"></i>

    <!-- Duotone -->
    <i class="stria-duotone stria-home"></i>
    ```
    
    If you are using the JS Replacer utility instead of CSS masks, use the `data-stria-style` attribute:
    ```html
    <i data-stria="home" data-stria-style="thin"></i>
    ```
  </Tab>
  <Tab value="React">
    In React, the style is seamlessly integrated into the component name exported from the core package. Simply import the desired style variation.

    ```tsx
    import { 
      HomeSolid, 
      HomeRegular, 
      HomeLight, 
      HomeThin, 
      HomeDuotone 
    } from 'stria-icons-react';

    export default function MyComponent() {
      return (
        <div className="flex gap-4">
          <HomeSolid className="w-6 h-6" />
          <HomeRegular className="w-6 h-6" />
          <HomeThin className="w-6 h-6" />
        </div>
      );
    }
    ```
  </Tab>
  <Tab value="Laravel Blade">
    When using the Blade components, you can specify the style by adding the style name directly to the component tag (`<x-stria-{style}-{name} />`).
    If no style is provided, it defaults to **Solid**.

    ```html
    <!-- Solid (Default) -->
    <x-stria-home />
    <x-stria-solid-home />

    <!-- Regular -->
    <x-stria-regular-home />

    <!-- Light -->
    <x-stria-light-home />

    <!-- Thin -->
    <x-stria-thin-home />

    <!-- Duotone -->
    <x-stria-duotone-home />
    ```
  </Tab>
</Tabs>
