Because Stria Icons are rendered as native SVGs and Webfonts, they inherit the text color of their parent element by default (`currentColor`). 

This means icons will automatically adapt to your application's light and dark mode themes without any extra configuration. However, you can explicitly color them when necessary.

## The Duotone Style

The **Duotone** style is unique because it consists of **two separate paths**: a primary layer and a secondary layer. 

By default, both layers inherit the same `currentColor`, but the secondary layer has an automatic `40%` opacity applied to it. This creates a sophisticated, translucent two-tone effect using just a single color code.

If you want absolute control, you can define two completely different colors for the layers using CSS variables:

```css
.my-custom-duotone {
  --stria-primary-color: #1d4ed8;   /* Blue primary */
  --stria-secondary-color: #93c5fd; /* Light Blue secondary */
  --stria-secondary-opacity: 1;     /* Remove default 40% opacity */
}
```

```html
<i class="stria-duotone stria-layer-group my-custom-duotone"></i>
```
