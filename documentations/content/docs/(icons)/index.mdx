# Introduction

Welcome to **Stria Icons**! Stria Icons is a meticulously crafted collection of open-source SVG icons, designed specifically as fill-based geometric shapes. This ensures pixel-perfect rendering across all screen resolutions without the scaling issues associated with stroke-based icons.

Stria Icons is available in five visual styles for every icon: **Solid**, **Regular**, **Thin**, **Light**, and **Duotone**.

## Key Features

- **Core-First Architecture**: SVG files are the single source of truth.
- **Pixel Perfect**: Meticulously designed on a 24x24 grid.
- **Fill-Based Design**: Scales naturally with parent font or size without stroke distortion.
- **Multiple Visual Styles**: Solid, Regular, Light, Thin, and Duotone variations.
- **Framework Integration**: Native wrappers for React and Laravel Blade.

## Packages

Stria Icons is split into separate packages depending on your stack:

- **Stria Icons (Core)**: Raw SVGs, Webfonts, CSS Masking utilities, and SVG Sprites.
- **Stria React**: Pure React functional component wrappers.
- **Stria Laravel**: Direct Laravel Blade components.
